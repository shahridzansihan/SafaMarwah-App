SafaMarwah Umrah Companion v1.7
1. Upload index.html, logo.png dan kaaba.jpg ke hosting statik HTTPS dalam folder yang sama.
2. Dapatkan URL aplikasi, misalnya https://domain-anda.example/index.html
3. Pada Blogger Page HTML View, gunakan kod dalam KOD_IFRAME_BLOGGER.txt dan gantikan URL_APP.
4. Sembunyikan tajuk halaman App melalui tetapan tema jika perlu.
5. Jangan terbit sebagai panduan agama rasmi sebelum semakan ilmiah dan pembetulan kandungan.
